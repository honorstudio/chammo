1. **시작할 때 docs/starter.md 를 읽고, 끝날 때 갱신한다.** 현재 단계, 끝낸 것, 다음 할 일 3~5개,

2. **부채는 생긴 그 자리에서 적는다** — 임시 코드, TODO, 건너뛴 것 — docs/roadmap.md 의 "기술 부채"에.
3. **새 로직과 버그 수정은 테스트 먼저** (버그를 재현하는 실패 테스트 → 수정).
[git] 4. **커밋은 작게** — 커밋 하나에 이유 하나, 되도록 300줄 이하. 디자인·영상·압축 원본은 커밋하지 않는다(.gitignore, 10MB 넘는 파일은 훅이 한 번 멈춘다) — 꼭 넣어야 하면 CHAMMO_BIG_OK=1 로 다시 커밋하고 이유를 커밋 메시지에.
[nogit] 4. **이 프로젝트는 git 을 쓰지 않는다** — git init·커밋·가지를 만들지 않는다. 고치기 전 원본은 사본으로 두고, 결과물은 이 폴더에 둔다.
5. **되돌리기 비싼 결정**(프레임워크·DB·호스팅)은 docs/decisions/ 에 짧은 ADR 로, 다시 볼 조건은 잴 수 있는 값으로.
[git] 6. 스크린샷·로그·덤프는 프로젝트 루트가 아니라 `.shots/`(git 제외)에.
