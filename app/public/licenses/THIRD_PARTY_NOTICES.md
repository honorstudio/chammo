# Third-party notices — Chammo

Chammo includes the open-source software listed below. Each component stays under its own license; this file gives recipients the notices those licenses require. Generated by `scripts/third-party-notices`; do not edit by hand.

**What is listed**

- Rust crates: what `cargo metadata` resolves for aarch64-apple-darwin and x86_64-pc-windows-msvc, following normal dependencies only. Crates reached only as dev-dependencies or build-dependencies are left out because they do not ship; proc-macro crates are kept because their output is compiled in. Crates in our own repository (path dependencies) are not third-party.
- Web packages: the transitive closure of `dependencies` in `app/package.json` (not `devDependencies`), following dependencies, optional dependencies and required peers that are installed. The closure is wider than the bundle, so a package may be listed without all of its code shipping. Left out: `@types/*` (type definitions only), packages restricted by `os`/`cpu` and `@napi-rs/canvas` (native Node.js add-ons that cannot run in the app's WebView).
- Fonts bundled with the app.

**How to read it**

- Identical license texts appear once, without their copyright lines. Each package line gives the name, version, ecosystem, declared license expression and that package's copyright lines (or its authors if the package states none).
- Where a package offers a choice of licenses, Chammo uses the one that has the license text in the package, preferring the most permissive; the section it appears in is that choice.
- Weak-copyleft components have their own sections with a link to their source. They are used unmodified.

**Notes**

- Univer (`@univerjs/*`, spreadsheets): open-source edition only; no Univer Pro package is included. Unmodified.
- Not in the installer, so not listed here: Craft apps (separate downloads, shown above this list in the app), the browser tool's `@playwright/mcp`, `playwright` and `playwright-core` (Apache-2.0, fetched by npm when the tool is first set up), and optional voice models, which you choose and download yourself.
