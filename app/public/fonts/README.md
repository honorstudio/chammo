# 번들 폰트 / Bundled font

- `ChammoHangul.woff2` — NAVER **D2Coding 1.3.2** 에서 한글 영역만 잘라 woff2 로 만든 **수정판**이다.
  D2Coding 은 SIL Open Font License 1.1 이고 "D2Coding" 이 예약 폰트 이름(Reserved Font Name)이라, 수정판은 그 이름을 쓸 수 없어
  폰트 이름을 **Chammo Hangul** 로 바꿨다. 라이선스 원문과 원 저작권 문구는 `OFL.txt`. 원본: https://github.com/naver/d2codingfont
  터미널에서 한글이 두 칸을 꽉 채워 자간이 벌어져 보이지 않게 쓴다.
- `ChammoHangul.woff2` is a **modified version** (Hangul subset, converted to woff2) of NAVER **D2Coding 1.3.2**, licensed under the
  SIL Open Font License 1.1. "D2Coding" is a Reserved Font Name, so this version is renamed **Chammo Hangul**. See `OFL.txt` for the
  copyright notice and the full license. Original: https://github.com/naver/d2codingfont
- 아이콘(상태줄 파워라인·Nerd Font 글리프)은 번들하지 않고 사용자 맥에 깔린 `MesloLGS… Nerd Font Mono`를 쓴다.
